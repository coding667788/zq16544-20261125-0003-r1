做 folioimpact，重放档案员关于文档封存与误传的事故记录。每份封存文档是多个版本化段的组合。仅有部分页在审阅副本中出现，某些页是同源折叠摘要，事后能证明等价却不提供新增独立信息。有一批见证证明某个组在一段时间内持有一版或两版文档，但并不确定是哪一版。每个组可能将已知内容合法交由同组另一个地点复核，交接区间与持有区间必须相交。所有输入均为自造符号，没有原文数据。
实现 bound CASE：对每个组、每个敏感段组、每个时间片，精确输出在所有满足见证的可能世界中可见的最少和最多独立段数，附取到两个边界的确定性版本分配与交换链。同时输出安全对策在所有合法世界中是否充分，不能把不确定状态一概算为已公开。实现 mitigate：从 16 个允许暂时停止复核、缩短区间或推荐替代版的动作中求最小代价计划，保留所有强制业务复核的最少信息边界，任何世界均满足保护上限。同价按条数和 ID；无解给可复核的相撞世界。歧义组件最多 14 个二选一变量，时间跨度十亿，用小实例全世界与逐段参考交叉校验。
从空仓库实现，使用 Windows 普通 CPU 和 Python 3.12 标准库，全部离线。交付 UTF-8 JSON CLI、明确的输入格式、README、合成夹具及 unittest。
